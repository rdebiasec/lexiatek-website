# LexiaTek Web Template

Local workspace for **Firma1 de Abogados LexiaTek**.  
GitHub production repo: **`lexiatek-website`**.

| Layer | Source |
|-------|--------|
| Visual | Aegis (Poppins/Lato, navy + blue/cyan) |
| Chassis | Pixel hierarchy (Vite `site/`, CSP, Formspree, CI Pages) |

## Quick start (dev)

```bash
cd site
npm install
npm run dev
```

→ http://localhost:5195/
