# Propuesta de asociación LexiaTek

El documento que se le entrega a Michele Aguilar es el **Word**, no el PowerPoint. El `.docx` es un **borrador** para que ella active control de cambios y corrija el lenguaje.

## Generar (local, no va a Git)

```bash
cd docs/propuesta
python3 build_propuesta_asociacion.py
```

Salida: `LexiaTek_Propuesta_de_Asociacion.docx`

Ábralo en Word o súbalo a Google Docs. Los `.docx` no se versionan.

## Cómo se lo da a ella

1. Word o Google Docs (no PDF, para que pueda reescribir).
2. Pedirle: Revisar → Control de cambios.
3. Los campos entre `[corchetes]` son solo cédula, tarjeta profesional, NIT, domicilio y datos análogos. El nombre Michele Aguilar ya está fijado.
4. Cuando el texto le represente: pacto de socios, licencia de la IA (DBX → LexiaTek) y autorización de sus servicios profesionales a LexiaTek; después constitución; después cumplimiento; después clientes.
